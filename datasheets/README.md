# Datasheets

This folder is a placeholder for locally-archived copies of component
datasheets used during development, for convenient offline reference.
Datasheet PDFs are not redistributed in this repository; instead, this
file lists the official sources.

| Component | Manufacturer | Official datasheet source |
|---|---|---|
| STM32G071RB | STMicroelectronics | https://www.st.com/en/microcontrollers-microprocessors/stm32g071rb.html |
| NUCLEO-G071RB | STMicroelectronics | https://www.st.com/en/evaluation-tools/nucleo-g071rb.html |
| HC-SR04 | Various (generic module) | Search "HC-SR04 ultrasonic sensor datasheet" — module is a common generic design without a single canonical manufacturer datasheet |
| SG90 servo | Various (generic module, originally TowerPro) | Search "SG90 servo datasheet" |
| PCF8574 I2C I/O expander (LCD backpack) | NXP / Texas Instruments (second-source variants exist) | https://www.nxp.com/products/PCF8574 |
| HD44780 LCD controller | Hitachi (original), widely second-sourced | Search "HD44780U datasheet" |

If you archive PDFs locally for your own reference, place them here and
update this table with the filename and revision date.
