# Images

This directory contains all visual assets used throughout the **Smart Parking Assistance System** repository.

The images are organized into dedicated folders for architecture, flowcharts, hardware illustrations, and concept results to maintain a clean and professional repository structure.

> **Note**
>
> This repository contains both documentation illustrations and concept graphics.
> Any image representing system output, dashboard, LCD screen, or parking visualization is clearly identified as a **Concept Illustration** and should not be interpreted as an actual hardware test or runtime capture.

# Image Guidelines

All images in this repository follow these principles:

- High resolution
- Professional documentation quality
- Consistent color scheme
- Dark engineering theme
- Suitable for GitHub documentation
- Optimized for fast loading
- Social preview image kept below **1 MB**

---

# Naming Convention

Images use lowercase filenames with underscores.

Example:

```
system_architecture.png
hardware_block_diagram.png
parking_decision_flowchart.png
concept_dashboard.png
```
