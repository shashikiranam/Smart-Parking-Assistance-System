# Flowcharts

This directory contains the flowcharts used to explain the execution
flow of the **Smart Parking Assistance System** firmware.

The diagrams provide a visual representation of the application's logic,
decision-making process, and state transitions.

> **Note:** These flowcharts are documentation assets created for design
> and implementation purposes. They are not runtime captures.

------------------------------------------------------------------------

## Folder Contents

  -----------------------------------------------------------------------------------
  File                               Description
  ---------------------------------- ------------------------------------------------
  `system_flowchart.png`             Overall project workflow from initialization to
                                     obstacle detection and user guidance.

  `firmware_flowchart.png`           Firmware execution flow showing initialization,
                                     peripheral handling, sensor acquisition, and
                                     control logic.

  `parking_decision_flowchart.png`   Decision-making algorithm used to generate
                                     parking guidance based on sensor distances.

  `state_machine.png`                Finite State Machine (FSM) representing firmware
                                     operating states and transitions.
  -----------------------------------------------------------------------------------

------------------------------------------------------------------------

## Purpose

These flowcharts help developers to:

-   Understand firmware execution.
-   Visualize module interactions.
-   Follow the parking decision logic.
-   Simplify debugging and maintenance.
-   Improve project documentation quality.

------------------------------------------------------------------------

## Flowchart Design Guidelines

All diagrams follow a consistent engineering style:

-   White background for print-friendly documentation
-   Standard flowchart symbols
-   Clear directional arrows
-   Consistent typography
-   High-resolution PNG format
-   Suitable for GitHub documentation
